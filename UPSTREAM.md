# Upstream provenance and attribution

This is a **third-party update of an official project**, not an official Asobo
release. The source originates from [Asobo Studio's Microsoft Flight Simulator
2020 glTF Blender importer/exporter](https://github.com/AsoboStudio/Microsoft-Flight-Simulator-2020-glTF-Blender-IO).

## Imported baseline

- Upstream commit: [`b3c2f174776ad9119999ce5b73106333a24bfeee`](https://github.com/AsoboStudio/Microsoft-Flight-Simulator-2020-glTF-Blender-IO/commit/b3c2f174776ad9119999ce5b73106333a24bfeee).
- Add-on version declared by that source: **3.3.2**.
- The initial source was supplied as the upstream `main` ZIP. Its archive comment
  contained the commit above. Its extracted Git tree was compared with that
  upstream commit and matched exactly.
- Published fork commits build on the upstream history, preserving the original
  authors and commit attribution. Local development snapshots are not presented
  as original authorship of the imported code.

## License and modification notices

The upstream [Apache License 2.0](LICENSE.md) is retained unchanged. Existing
